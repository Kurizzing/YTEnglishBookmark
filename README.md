# EngBookmark · 영어 듣기 북마크

유튜브에서 놓친 시점과 연습할 구간을 저장하는 Chrome 확장 프로그램입니다. 서버, 로그인, 빌드 과정 없이 사용합니다.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더(`manifest.json`이 있는 `EngBookmark`)를 선택합니다.
4. 이미 열려 있던 유튜브 탭을 새로고침합니다.
5. 크롬 도구 모음의 퍼즐 아이콘에서 **EngBookmark**를 고정하면 편리합니다.

## 사용법

| 조작 | 동작 |
| --- | --- |
| Q | 현재 시점을 저장하고 계속 시청 |
| W → W | 시작점과 끝점을 지정해 구간 저장. 저장 직후에는 반복하지 않음 |
| 시점 북마크 클릭 | 해당 영상의 저장 시점으로 이동하고 재생 |
| 구간 북마크 클릭 | 해당 영상의 저장 구간을 자동 반복 |
| Esc / 영상 위 해제 버튼 | 구간 지정 취소 및 반복 해제 |

유튜브 페이지에 포커스가 있어야 단축키가 동작합니다. 한글 입력 상태에서도 물리적인 Q/W 키를 사용하며, 검색·댓글 입력 중이나 한글 조합 중에는 작동하지 않습니다. Ctrl/Alt/Shift/Windows 조합과 키를 길게 누르는 입력은 처리하지 않습니다.

확장 아이콘을 클릭하면 **저장 날짜 기준 연 → 월 → 일** 폴더가 나타납니다. 영상 제목과 시간을 클릭해 재생하고, 체크박스로 여러 항목을 선택하거나 폴더의 삭제 버튼으로 일괄 삭제합니다. 모든 삭제는 개수를 확인한 뒤 실행됩니다.

동일 영상 탭을 우선 재사용합니다(현재 창 우선). 없으면 현재 창의 유튜브 탭을 재사용하고, 그마저 없으면 새 탭을 엽니다. 다른 영상을 보고 있던 유튜브 탭이 이동할 수 있습니다.

## 저장과 지원 범위

- 북마크는 현재 크롬 프로필의 `chrome.storage.local`에 보관하며 재시작 후에도 유지됩니다. 확장 프로그램을 제거하면 함께 삭제됩니다. 계정 동기화는 지원하지 않습니다.
- 날짜는 저장 당시 컴퓨터의 현지 날짜로 고정됩니다. 시점은 소수 초까지 저장하며 목록에서는 초 단위로 표시합니다.
- 데스크톱 `https://www.youtube.com/watch?v=...` 일반 영상만 지원합니다. Shorts, 실시간 방송, 외부 임베드 영상은 지원하지 않습니다.
- 광고 재생 중에는 저장·시점 이동·구간 반복을 보류합니다. 광고를 건너뛰거나 차단하지 않습니다.
- 구간 반복 중 일시 정지는 그대로 유지합니다. 구간 밖으로 수동 탐색한 뒤 재생하면 다시 저장 구간으로 돌아갑니다. 자유롭게 탐색하려면 반복을 해제하세요.
- 브라우저가 자동 재생을 제한하면 영상의 재생 버튼을 한 번 눌러 주세요. 사용할 수 없거나 길이가 달라진 영상은 안내 메시지를 표시합니다.
- 유튜브 페이지 구조가 바뀌면 영상 탐지 로직을 조정해야 할 수 있습니다. 확장 프로그램을 업데이트/다시 로드한 뒤에는 유튜브 탭도 새로고침하세요.

## 개발과 검증

Node.js 20 이상에서 `npm test`로 테스트합니다. npm 패키지 설치는 필요 없습니다. 배포용 파일은 폴더의 HTML/CSS/JavaScript, `manifest.json`, `icons/`입니다.

Node.js 22 이상과 Chrome이 있으면 `npm run test:browser`로 별도 임시 프로필의 헤드리스 크롬에서 팝업 레이아웃·재생 요청·삭제 확인/취소를 검증합니다. 설치 위치가 기본값과 다르면 `CHROME_PATH` 환경 변수에 크롬 실행 파일 경로를 지정합니다. 이 테스트는 모의 북마크 저장소를 사용하며 실제 유튜브 재생 검증을 대체하지 않습니다. 스크린샷은 `.test-artifacts/`에 생성됩니다.

- `background.js`: 저장·삭제 직렬화, 탭 선택, 재생 요청 전달. 대기 요청은 서비스 워커 재시작에도 유지되는 세션 저장소를 사용합니다.
- `content.js`: 키 입력, 영상 준비·광고 확인, 구간 반복, 영상 위 알림.
- `popup.*`: 날짜별 목록, 선택, 삭제 확인.
- `core.js`: 데이터 생성, 날짜 분류, 탭 우선순위, 구간 지정 상태.

실제 유튜브에서 확인할 항목:

1. Q 저장 후 팝업에서 제목·시점·오늘 날짜를 확인합니다.
2. W 시작 → 뒤로 탐색 후 W(끝점 오류) → 앞으로 탐색 후 W로 저장하고, 즉시 반복되지 않는지 확인합니다.
3. 시점과 구간을 각각 선택하고 구간 반복, 일시 정지, Esc/버튼 해제를 확인합니다.
4. 검색창·댓글·한글 조합 중 입력이 저장되지 않는지 확인합니다.
5. 다른 영상 북마크, 새 탭, 전체 화면, 광고 전후, 유튜브 내부 이동, 빠른 항목 전환을 확인합니다.
6. 시험용 북마크로 개별·선택·폴더 삭제와 취소를 확인합니다.
7. 크롬을 재시작해 저장 데이터가 유지되는지 확인합니다.
